# Docket

Lists, cards, a focus timer and work-hour tracking, made for your phone. Installable web app.

Open **https://ethecho-ui.github.io/docket/** and use "Install Docket" in the menu (or the browser's install option).

- Categories with Trello-style lists and cards; long-press to drag on a phone
- Tags, due dates, checklists, notes
- Pomodoro timer, task timers, work hours per job, earnings, stats, Excel export
- Data stays on the device; optional sync through a sync folder or a private GitHub repository
- Optional push reminders through a small Cloudflare Worker
